개인정보 안내

이 안내는 소유자 본인만 사용하는 개인 자동화 도우미에 적용됩니다.

접근하는 정보와 목적

계정 연결 시 승인한 범위의 계정 정보와 인증 정보를 사용합니다. 일정 연결의 경우 캘린더 목록과 일정 내용을 조회하고, 소유자가 요청한 일정을 등록·수정하는 데 사용합니다.

처리와 보관

계정 데이터는 소유자가 지정한 처리 환경에서 요청한 작업을 수행하는 데 사용됩니다. 이 공개 안내 사이트에는 계정 데이터나 인증 정보를 저장·게시하지 않습니다. 이 사이트에는 입력폼, 추적 스크립트 또는 분석 도구가 없습니다. 웹 호스팅 제공자는 페이지 전송 과정에서 접속 정보를 처리할 수 있습니다.

접근 철회와 삭제

소유자는 연결한 계정의 보안 설정에서 앱 접근을 철회할 수 있습니다. 저장된 인증 정보와 작업 데이터의 삭제는 소유자가 관리 환경에서 직접 처리합니다. 접근 철회가 저장 데이터의 자동 삭제를 의미하지는 않습니다.

문의

일반 사용자 가입이나 데이터 수집을 받지 않는 개인용 도구입니다. 연결 및 데이터 관리 문의는 앱 권한 동의 화면의 지원 연락처를 이용합니다.
